# 부산 야간 병원 지도

밤이나 휴일에 갈 수 있는 부산의 응급의료기관과 소아 야간·휴일 진료기관을 한 지도에서 보는 웹페이지입니다.

**보러 가기:** https://pyropos123-coder.github.io/busan-night-hospital/

> 응급 상황에서는 먼저 **119**에 연락하세요. 진료 시간과 진료 가능 여부는 바뀔 수 있으니 방문 전에 병원에 꼭 확인하세요.

## 보여 주는 병원

| 종류 | 데이터 | 갱신 |
| --- | --- | --- |
| 권역응급의료센터 · 지역응급의료센터 · 지역응급의료기관 | 국립중앙의료원 전국 응급의료기관 정보 조회 서비스 (공공데이터포털) | 매주 월요일 새벽 3시(한국 시간) 자동 |
| 달빛어린이병원 | 부산시 안내와 보도를 보고 직접 정리 | 수동 |
| 취약지 소아 야간·휴일 진료기관 | 부산시 안내와 보도를 보고 직접 정리 | 수동 |

달빛어린이병원과 취약지 소아 진료기관은 2026년 10월 기준으로 정리했고, 모든 기관이 포함되었다고 보장하지 않습니다.

## 구성

- `index.html` : 지도 페이지 (카카오맵 JavaScript SDK 사용)
- `config.js` : 카카오 JavaScript 키 (도메인 등록으로 보호되는 키만 넣습니다)
- `emergency.json` : 응급의료기관 목록 (자동 생성)
- `update_emergency.py` : 목록을 받아 `emergency.json`을 만드는 스크립트
- `.github/workflows/update.yml` : 매주 스크립트를 실행하는 GitHub Actions 설정

## 운영 메모

- 공공데이터포털 인증키는 코드에 넣지 않고 저장소 Secrets의 `DATA_GO_KR_KEY`에만 저장합니다.
- 달빛어린이병원 등을 고치려면 `index.html`의 `MANUAL` 목록을 수정합니다.
- 오랫동안 저장소에 변화가 없으면 GitHub이 예약 실행을 멈출 수 있으니, Actions 탭에서 가끔 확인하세요.
- 내 위치 기능은 브라우저 안에서만 쓰이며 서버로 보내거나 저장하지 않습니다.
